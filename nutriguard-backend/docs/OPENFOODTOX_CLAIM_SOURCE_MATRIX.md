# OpenFoodTox pilot -- editorial claim/source matrix

Mechanically generated by `python -m scripts.openfoodtox.export_docs claim-matrix` directly from `scripts/openfoodtox/editorial_content.py` -- never hand-transcribed. `... export_docs claim-matrix --check` fails loudly if this file and that module ever disagree. Per `docs/OPENFOODTOX_DELIVERY_CONSISTENCY_TASK.md` item 2, full source text (not truncated) is kept here so a reviewer can follow every citation without opening the module; the EN claim text is still shown abbreviated (full text next to the field name indicated, in `editorial_content.py`) since reproducing every claim's whole paragraph here would duplicate, not aid, review.

**Source kinds**: `openfoodtox_dossier` (an OpenFoodTox-extracted quote/field), `tracked_seed_csv`/`tracked_seed_json` (NutriGuard's own already-curated, git-tracked seed data -- a content *origin*, never independent scientific evidence on its own), `external_primary_source` (a primary document read directly in this session, with its own citation). **`review_status`**: `not_reviewed` for every row -- source tracing by an agent is not independent scientific or translation approval; `internal_only_never_shown_to_consumer` rows never appear in `draft_en`/`draft_bg` at all.
